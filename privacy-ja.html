プライバシーポリシー

Aguantín アプリ（com.jrsoft.bateria）· 最終更新日：2026年11月17日

ひとことで言うと：このアプリにはユーザーアカウントもサーバーもなく、バッテリーの測定値、充電の履歴、充電器テストの結果、設定がお使いの端末の外に出ることはありません（ご自身で新しい端末に移す場合や、履歴をエクスポートする場合を除きます）。データを送信するのは広告だけで、それを行うのは Google のライブラリです。

このポリシーはスペイン語版を基準としており、このページはその同じ版の翻訳です。

このアプリが「しない」こと

  • 登録、アカウント、ユーザー情報、独自のサーバーはいずれもありません。アプリはすべてお使いの端末の中で動作します。
  • 独自の分析ツールやクラッシュレポートのツールは一切ありません。Google Analytics も Crashlytics も、それに類するものもありません。独自にデータを第三者へ送信するライブラリは広告用のものだけで、これについては後で説明します。本アプリには Firebase のリモート設定ライブラリ（Remote Config）が含まれています。これは新しいバージョンを公開せずに広告を調整するために使えるものですが、無効にしてあります。起動することも、どのサーバーに接続することもありません。将来これを有効にする場合は、その前にこのポリシーを更新します。
  • 端末の位置情報、カメラ、マイク、連絡先、写真やファイルは使いません。バッテリーの情報を読み取るのに権限は必要ありません。Android はその情報をどのアプリにも提供しているからです。
  • ほかにどのアプリが入っているか、それぞれがどれだけ消費しているかは見ません。
  • JR Soft はお客様のデータを保管しません（お客様から届いたメールを除きます）。また、それを含む一覧やデータベースを誰かに渡すこともありません。広告を表示して効果を測定するために、Google の広告 SDK（AdMob）が端末の識別子やその他の技術的なデータを独自に収集し、Google に送信します。その内容はこのポリシーで説明しています。米国の一部のプライバシー法では、第三者の SDK にこうしたデータをパーソナライズド広告のために収集させることを、個人データの「販売」または「共有」とみなします。米国にお住まいの方は、これを拒否できます（「米国にお住まいの方」をご覧ください）。

端末の中だけに残るデータ

これらの情報はアプリ専用の保存領域に保存され、そこから外に出ることはありません。アプリをアンインストールするか、Android の設定からアプリのデータを削除すると（「設定」→「アプリ」→「Aguantín」→「ストレージ」→「データを削除」）、すべて消去されます。

  • バッテリーの測定値：日時、残量、充電中かどうか、充電器の種類（ACアダプター、USB、ワイヤレス）、温度、電圧、おおよその電流、端末の充電カウンター。アプリを閉じているときはバックグラウンドで、約15分ごとに、充電中はそれより頻繁に記録します。
  • 充電の記録：それぞれの充電の開始と終了の時刻、何%から何%まで充電したか、使った充電器、最高温度と最大電流、充電された量。
  • 推定した健康度：充電の記録からアプリが計算した容量、サイクル数（メーカーが値を記録している場合に Android 14 以降が報告するものと、アプリが数えたもの）、そしてご自身で入力した場合に限り公称容量。
  • 充電器テストの結果：テストに付けた名前と、それぞれの測定結果（平均電流と平均電力、電圧、残量、時間）。アプリから1件ずつ削除できます。
  • 設定：スタイル、テーマ、温度の単位、受け取りたい通知とその残量や温度、ステータス通知を表示するかどうか。
  • アプリがこの端末について学習したこと：端末が電流をどの単位とどの符号で報告するか、これまでに確認された充電の上限（たとえば 80% で止まるかどうか）、同じ通知を繰り返さないための送信済みの通知。
  • アプリの評価を最後にお願いした日付。120日に1回より多くお願いしないためのものです。
  • 端末のメーカーとモデル。「ガイド」がお使いのブランド向けの手順を表示するために、その場で参照します。保存も送信もしません。
  • SIM カードの国（SIM がない場合はシステムの地域）。「JR Soft のその他のアプリ」画面が、お住まいの国で入手できるアプリだけを表示するために、その場で参照します。保存も送信もしません。この画面と「アプリを共有」の Google Play へのリンクには、このアプリからのリンクであることを示すタグが付きますが、お客様のデータは一切含まれません。

通知、ウィジェット、クイック設定タイルは、これらのデータをもとに端末の中で作られます。どれもサーバーを経由しません。インターネットから送られてくる通知はありません。ウィジェットはホーム画面にバッテリー残量を表示するため、端末を見た人なら誰でも目にすることができます。

履歴のエクスポート

「履歴をエクスポート（CSV）」をタップすると、アプリは測定値と充電の記録を含むファイルを端末内に作成し、Android でどのアプリに送るか（メール、クラウドストレージ、メッセージアプリなど）を選べます。送信するのはお客様ご自身で、送り先もお客様が選んだところだけです。それ以降は、そのアプリのプライバシーに関する条件が適用されます。JR Soft には何も届きません。

バックアップ、機種変更、移行されないもの

Android のクラウドバックアップ（Google アカウントのバックアップ）は、このアプリのデータについては無効にしてあり、何もアップロードされません。Android は再インストールのために、インストールしていたアプリの一覧をアカウントに保存しますが、この一覧は Google が管理しており、アプリのデータは含まれません。

新しい端末をセットアップするときに、ケーブルの有無にかかわらず古い端末から直接データをコピーすると、履歴、充電の記録、充電器テスト、設定が新しい端末に移ることがあります。この移行はお客様が求めるもので、Android が、Android 自身のツールまたは端末メーカーのツールを使い、それぞれの条件のもとで行います。Android のドキュメントによれば、データはサーバーを経由せずに端末から端末へ移されます。当方のサーバーを経由することは決してなく、JR Soft には何も届きません。移行されるかどうかは Android のバージョンとメーカーによって異なるため、保証はできません。Android 7 と 8 では何も移行されません。

古い端末でしか意味のないものは移行されません。具体的には、アプリがその端末について学習したこと（電流の単位、充電の上限、送信済みの通知）、広告に関するお客様の選択、広告の内部状態です。新しい端末では、必要なことをアプリがあらためてお尋ねします。

端末の外に送られるデータ

広告：Google AdMob

このアプリは、Google の広告 SDK（AdMob）が配信する控えめな広告を表示します。「履歴」と「健康度」の画面の下部にバナーを、また履歴の充電の記録の間と、充電の詳細の最後に「広告」と表示したネイティブ広告を表示します。全画面広告は一切なく、バッテリーの状態、「ガイド」、通知、ウィジェット、設定にも広告は表示しません。広告のために、アプリは com.google.android.gms.permission.AD_ID 権限を宣言しています。これにより Android の広告 ID にアクセスできます。この ID は「Android の設定」→「Google」→「広告」（端末によっては「設定」→「プライバシー」→「広告」）からリセットや削除ができます。

広告 ID に加えて、AdMob SDK はアプリセット ID（app set ID）、アプリや広告での操作、診断データ（起動時間、フリーズ、電力消費）を収集します。Google は IP アドレスを使って、市区町村程度のおおよその位置を推定することがあります。Google はこれらのデータを、広告の配信と効果測定、統計、不正防止のために、Google 自身のポリシーに従って使用します。対応している端末では、SDK が Android の広告機能（Privacy Sandbox）を使うこともあります。これは Android のプライバシー設定で管理できます。

欧州経済領域、英国、スイス、および法律で求められる地域では、アプリはパーソナライズド広告を配信する前に Google の同意フォーム（UMP）を表示します。選択はいつでも「設定」→「広告のプライバシー設定」から変更できます。

広告の同意メッセージは、Google がすべての広告パートナーに共通の文面で表示しているため、正確な位置情報について触れています。Google によれば、Google の広告 SDK が使うのは IP アドレスから推定したおおよその位置だけで、このアプリが位置情報を渡すことはありません。この利用は「オプションを管理」で拒否できます。

バッテリーのデータが広告に渡ることは決してありません。広告のリクエストには、お客様の測定値、充電の記録、設定は一切含まれません。同意を拒否した場合は、パーソナライズされていない広告または制限付きの広告が表示されますが、アプリはまったく同じように動作します。使えなくなる機能はありません。

評価、共有、お問い合わせ

アプリを評価する場合、評価の画面は Google Play のもので、評価は Google のポリシーに従い、お客様のアカウントとともに Google が受け取ります。「アプリを共有」は、お客様が選んだアプリにリンクを渡します。「お問い合わせ」からご連絡いただく場合は、お客様ご自身のメールアプリからメールを送ることになり、当方にはメールアドレスとお書きいただいた内容が届きます。

IP アドレス

インターネットに接続するアプリはどれもそうですが、広告をリクエストする際に、Google のサーバーがお客様の IP アドレスを受け取ります。このアプリがそれ以外のサーバーに接続することはありません。

法的根拠と保存期間

法的根拠。端末の中で処理されるものは JR Soft には届きません。測定値、充電の記録、テスト、設定は、お客様が求めることをアプリが行えるように保存されます（GDPR 第6条第1項(b)）。端末の外に送られるものについては次のとおりです。(1) 欧州経済領域、英国、スイスにおけるパーソナライズド広告と、広告目的での端末のストレージの利用：お客様の同意。同意は Google のフォームで与えるか拒否するかを選び、「設定」→「広告のプライバシー設定」で撤回できます（GDPR 第6条第1項(a)、スペインの LSSI-CE 第22条第2項）。(2) パーソナライズされていない広告、その効果測定、技術的なログ、不正防止：無料アプリの運営資金をまかない、アプリを正常に動作させ、不正から守ることについての正当な利益（GDPR 第6条第1項(f)）。(3) 当方にご連絡いただいた場合：返信し、ご連絡の内容を解決することについての正当な利益（GDPR 第6条第1項(f)）。Google は AdMob のデータを、独立した管理者として自らのポリシーに従って取り扱います。

端末に保存されたデータは、お客様が削除するか、アプリをアンインストールするか、アプリのデータを消去するまで残ります。履歴に日数の上限はありません。記録するのは多くても4分に1回なので、データはあまり増えません。このアプリは、お客様から届いたメッセージを除き、端末の外にデータを一切保存しません。そのメッセージは、用件が解決した時点で、遅くとも受信から1年後までに削除します。Google は自らのデータを、Google のポリシーに従って保存します。

セキュリティ

アプリが保存するデータはアプリ専用の保存領域にあり、Android はほかのアプリがそこにアクセスすることを許可しません。また、クラウドバックアップにはアップロードされません。アプリには情報漏えいが起こりうる独自のサーバーやアカウントはなく、インターネットから受け取るデータは広告だけです。エクスポートしたファイルはアプリ専用のフォルダに作成され、お客様が共有したときにだけ外に出ます。Google の広告 SDK の通信は暗号化（TLS）されています。お客様から届いたメッセージは JR Soft だけがアクセスできるメールアカウントに保管し、上記の期間内に削除します。

お客様の権利

欧州経済領域、英国、スイスにお住まいの場合、GDPR（またはお住まいの国の同等の法律）により、アクセス権、訂正権、消去権、処理の制限の権利、データポータビリティの権利、異議を述べる権利が認められています。実際には、このアプリは端末の外にお客様個人に結びつくデータを一切保存していないため、次のようになります。

  • アクセスとデータポータビリティ：アプリが保存しているものはすべてアプリ内（「履歴」、「健康度」、充電器テスト）で確認でき、「履歴をエクスポート（CSV）」で持ち出すことができます。
  • 訂正と消去：公称容量の変更や削除、充電器テストの1件ずつの削除、Android の設定からのアプリのデータの全消去、アプリのアンインストールができます。広告 ID は Android の設定からリセットまたは削除できます。
  • 異議と同意の撤回：「設定」→「広告のプライバシー設定」。通知については、アプリ内または Android の通知設定から行えます。

Google のライブラリが収集するデータは Google が管理しており、それに関する権利は Google に対して行使します：policies.google.com/privacy。また、スペインデータ保護庁（AEPD）、またはお住まいの国のデータ保護機関に苦情を申し立てることもできます（GDPR 第77条）。

米国にお住まいの方

独自のプライバシー法がある米国の州（たとえばカリフォルニア州、コロラド州、コネチカット州、テキサス州、バージニア州）にお住まいの場合、ご自身の個人データを販売しないこと、またターゲティング広告のために共有しないことを求める権利があります。これはアプリ内で行えます：「設定」→「広告のプライバシー設定」→ データを販売・共有しないためのオプション。それ以降は、パーソナライズされていない広告または制限付きの広告が表示されます。バッテリーの測定値、充電の記録、設定は端末の中に残り、誰にも送信されません。広告のために、Google の SDK は端末の識別子とおおよその位置（市区町村レベル）を使います。データに関するその他のご依頼は、demual@gmail.com までお寄せください。

また、当方が保有しているお客様のデータの内容を知ること、その削除や訂正を求めることもでき、それによって不利な扱いを受けることはありません。過去12か月間に Google の SDK が広告のために収集した可能性のあるデータの種類は、識別子（端末と広告の識別子）、アプリ内のアクティビティ（広告での操作）、IP アドレスから推定したおおよその位置です。機微なデータは収集されません。JR Soft が保管するのは、お客様から届いたメールだけです。このポリシーは少なくとも年に1回見直します。

ブラジルにお住まいの方

ブラジルにお住まいの場合、一般データ保護法（LGPD、法律第13.709/2018号）により、とりわけ、処理の有無の確認とアクセス、訂正、匿名化または削除、データポータビリティ、データの共有先に関する情報、同意の撤回の各権利が認められています（第18条）。JR Soft は端末の外にお客様のデータを保存していないため、これらの権利は「お客様の権利」で説明した方法で行使できます。広告のデータに関する権利は Google に対して行使します。Google はそのデータを、自らの保護措置のもとでブラジル国外で取り扱うことがあります。広告は、無料アプリの運営資金をまかなうという正当な利益に基づいています（第7条第IX号）。ご連絡は demual@gmail.com までお願いします。ANPD（Autoridade Nacional de Proteção de Dados）に苦情を申し立てることもできます。

未成年の方

Aguantín は成人向けのアプリで、18歳未満の方を対象としていません。未成年者のデータを故意に収集することはありません。AdMob が送信する技術的なデータは、上記で説明したとおりです。

Aguantín についての注意事項

「バッテリーの健康度」とは端末のバッテリーのことで、お客様の健康のことではありません。Aguantín には健康に関する機能は一切ありません。容量、サイクル数、電流、予測は、それぞれの端末が報告する値にもとづく推定であり、メーカーによる測定値ではありません。Samsung と Pixel はそれぞれの所有者の商標です。Aguantín はそれらの設定がどこにあるかを説明しているだけで、それらとは提携していません。
